# Sample Audio Files

To respect copyrights and repository size limits, binary audio files are not committed directly to git.

### Obtaining Test Audio:
1. **Mozilla Common Voice**: Download open-license CC0 / CC-BY voice samples from [Common Voice Data](https://commonvoice.mozilla.org/).
2. **Synthetic Generation**: You can use `scripts/smoke_test.py` or `scripts/benchmark.py` which dynamically generate test audio signals in memory.
